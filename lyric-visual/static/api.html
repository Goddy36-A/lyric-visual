Lyric Visuals API

Send lyric lines, get back a matching image or video link for each line. Works from any desktop, Android, iOS or web app that can make an HTTPS request.

Base URL and authentication

Base URL:

Every /v1 request needs your key in the X-API-Key header. The key is the APP_API_KEY value set on the server. Missing or wrong key returns 401.

Keys shipped inside an app can be extracted. Rotate the key on the server if it leaks.

Endpoints

Method and pathUse
POST /v1/visualsMany lines in one call (max 200). Best for a whole song.
GET /v1/visualOne line, query parameters only.
GET /healthNo key needed. Use it to wake the server.

Request fields (POST /v1/visuals)

FieldTypeMeaning
linesstring listRequired. One lyric line per scene.
mediastringimage (default) or video.
stylestringOptional words added to every search, such as dark moody cinematic.
default_querystringFallback search when nothing matches. Default abstract light.

GET /v1/visual takes line, media and style as query parameters.

Response

[
  {
    "line": "I cry in the rain",
    "query": "rain window",
    "url": "https://cdn.pixabay.com/...",
    "media": "image"
  }
]

The list has one item per input line, in the same order. url can be null if Pixabay returned nothing, so show a fallback background. Adjacent lines with the same query share the same url. Errors: 400 too many lines, 401 bad key, 503 server key not configured.

Code for your apps



Use long timeouts (60 to 90 seconds) and retry once. The free server sleeps when idle and the first call wakes it.
